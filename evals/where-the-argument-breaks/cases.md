# where-the-argument-breaks: paired cases

All facts, rules, and authorities are fictional.

## 1. What did the manufacturer learn?

Draft (both variants): "Before the accident, the manufacturer had received a report that this latch model opened under load."

- **A.** Record: a service email received before the accident says the paint chipped on this model.
- **B.** Record: the same email says the latch on this model opened while supporting a load.

Expected: In A, timing and receipt are supported, but the subject of the report is wrong. The repair is to describe the paint complaint or find a report about the latch opening. In B, the sentence accurately describes the report. Demanding proof that the defect actually existed tests a claim the writer never made.

## 2. What made the precedent come out that way?

Supplied opinion: in *Vale*, the courier owed a duty to safeguard a parcel because the sender surrendered the only key to the courier's locked compartment.

Draft (both variants): "As in *Vale*, the sender placed the parcel in a locked compartment. The courier therefore undertook the same duty."

- **A.** Stipulation: only the sender kept a key.
- **B.** Stipulation: the sender handed the only key to the courier. The preceding sentence of the draft states that fact.

Expected: In A, the shared lock hides a decisive difference in control. Distinguish *Vale* and find another basis for a duty. In B, read the sentences together. The preceding sentence supplies the material relationship, so the argument stands.

## 3. Would winning the point change the order?

Supplied rule: each independently sufficient ground must be displaced before the panel may vacate.

Draft (both variants): "The order rests on late service. The stipulated return shows timely service. The panel should vacate."

- **A.** Order: dismissed for late service and, independently, for failure to pay the fee. The fee ruling is unchallenged.
- **B.** Order: dismissed solely for late service.

Expected: In A, the draft misstates the order. Proving timely service leaves the fee ruling intact. In B, the stipulated return answers the only ground, and the requested disposition follows.
