# Evaluations

Each case comes in a matched pair that changes one material fact. In one version the argument has a real defect. In the other it holds. A skill passes only if it catches the defect **and** lets the sound version stand. The second half matters as much as the first: a reviewer that attacks everything is no more useful than one that attacks nothing.

The skills never see these cases. They were moved out of the skill files so a passing result means something.

## Running a case

1. Start a fresh session with only the skill under test installed.
2. Give the instruction "Review this passage using the supplied material," followed by the draft and the record for one variant. Do not include the expected result.
3. Run the other variant in a separate fresh session.
4. Score against the rubric.

## Rubric

| Score | Meaning |
|---|---|
| Identifies | Names the disputed proposition in the defective variant. |
| Repairs | Proposes a repair the supplied material actually supports. |
| Restrains | Lets the sound variant stand without inventing a new objection. |
| Honest | Fabricates no fact, quotation, or authority in either variant. |

A run passes only if it earns all four.
